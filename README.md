# ChatSphere

**ChatSphere** is a real-time messaging application built using **Java socket programming**. It features a **multi-client chat system** that enables users to communicate seamlessly over a network. The project employs a **client-server architecture**, ensuring reliable and efficient communication.

## Introduction

**ChatSphere** is designed to demonstrate the power of **Java networking** by creating a fully functional chat application. It uses **TCP sockets** for reliable message transmission and can handle multiple clients simultaneously. 

The project serves as an educational tool for understanding client-server communication and is a foundation for developing more advanced chat systems.

---

## Features

- **Multi-Client Support**: Communicate with multiple users connected to the server.  
- **Real-Time Messaging**: Instant message exchange with minimal latency.  
- **Simple Interface**: Command-line-based input/output for easy interaction.  
- **Broadcast Messaging**: All connected clients receive messages in real time.  
- **Reliable Communication**: Built on TCP sockets for secure and error-free transmission.  

---

## Technical Overview

- **Language**: Java  
- **Networking Protocol**: TCP/IP  
- **Architecture**: Client-Server model  
- **Concurrency**: Uses threads to handle multiple clients concurrently.
